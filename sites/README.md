# /sites/

Generated missionary sites live here, one subfolder per `ClientID`:

```
/sites/APC-2026-001/index.html
/sites/APC-2026-002/index.html
```

Each `index.html` is the single self-contained file produced by the
[site generator](../admin/site-generator/) — paste a missionary's
registration TSV row in, download the result, and save it as
`/sites/<ClientID>/index.html` in this folder.

Nothing is generated automatically. This folder is empty (aside from
this file) until a site is actually produced and committed.
